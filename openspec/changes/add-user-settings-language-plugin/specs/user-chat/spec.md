# Spec Delta

## MODIFIED Requirements

### Requirement: Отсутствие эха и автоответа на нажатие кнопки у пользователя

Сообщение, порождённое нажатием кнопки, SHALL НЕ отображаться в чате самого пользователя: оно не появляется в его списке сообщений ни сразу, ни через SSE-поток, ни при повторной загрузке истории. Автоматический ответ бота на нажатие SHALL отсутствовать, кроме случая, когда payload кнопки обрабатывает плагин, явно объявивший приём нажатий кнопок.

#### Scenario: Нет локального эха

- **WHEN** пользователь нажимает кнопку
- **THEN** в его чате не появляется новое сообщение от его имени

#### Scenario: Нет доставки через SSE

- **WHEN** коллбэк-сообщение пользователя создано на сервере
- **THEN** оно не доставляется в SSE-поток этого пользователя

#### Scenario: Плагины не отвечают на нажатие

- **WHEN** `callback_data` нажатой кнопки совпадает с условием срабатывания плагина (например `ping`)
- **THEN** автоматический ответ бота в диалоге не появляется

#### Scenario: Кнопка пресета оператора остаётся тихой

- **WHEN** пользователь нажимает кнопку, приложенную оператором консоли из пресета, и её payload не обрабатывается ни одним плагином с приёмом нажатий
- **THEN** автоматический ответ бота не появляется, нажатие видно только оператору

#### Scenario: Нажатие, обработанное плагином, отвечает

- **WHEN** пользователь нажимает кнопку, payload которой обрабатывает плагин, объявивший приём нажатий (например кнопка выбора языка в сообщении настроек)
- **THEN** в диалоге появляется обычный ответ бота (сохранён в истории и доставлен по SSE), а само нажатие по-прежнему скрыто из истории и SSE этого пользователя

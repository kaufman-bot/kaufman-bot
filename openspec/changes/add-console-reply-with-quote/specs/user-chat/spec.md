# Spec Delta

## ADDED Requirements

### Requirement: Цитата в ответе оператора

Когда оператор ответил в консоли со ссылкой на сообщение пользователя, созданный ответ бота SHALL доставляться пользователю с снимком цитируемого сообщения (`replyTo`: идентификатор, отправитель и текст исходного сообщения) — и в истории диалога, и в SSE-потоке. Фронтенд страницы `/chat` SHALL отображать этот снимок визуально как цитату над текстом ответа. Сообщения, созданные без ссылки, SHALL иметь пустой снимок и отображаться в чате пользователя без блока цитаты.

#### Scenario: История содержит снимок цитаты

- **WHEN** пользователь запрашивает историю диалога, в которой есть ответ оператора с ссылкой на его сообщение
- **THEN** этот ответ возвращается со снимком цитируемого сообщения (идентификатор, отправитель, текст)

#### Scenario: SSE доставляет снимок цитаты

- **WHEN** оператор отправляет ответ с ссылкой на сообщение пользователя, а чат пользователя открыт
- **THEN** пользователь получает SSE-событие этого ответа со снимком цитируемого сообщения

#### Scenario: Визуальное отображение цитаты в чате

- **WHEN** ответ оператора со снимком цитаты появляется в переписке `/chat`
- **THEN** над его текстом отображается цитируемое сообщение исходного отправителя

#### Scenario: Ответ без цитаты отображается как обычно

- **WHEN** в чат пользователя приходит ответ бота, созданный без ссылки на сообщение
- **THEN** он отображается как обычно, без блока цитаты

### Requirement: Пометка двойной доставки в чате пользователя

Фронтенд страницы `/chat` SHALL отображать у ответов бота, у которых `deliveredTo` содержит Telegram, пометку, что сообщение также доставлено в Telegram; ответы без Telegram в `deliveredTo` SHALL отображаться без пометки доставки.

#### Scenario: Пометка у продублированного в Telegram ответа

- **WHEN** в чат приходит ответ бота с `deliveredTo`, содержащим оба канала
- **THEN** у сообщения видна пометка о дополнительной доставке в Telegram

#### Scenario: Ответ только в веб — без пометки

- **WHEN** в чат приходит ответ бота с `deliveredTo`, содержащим только `WEB`
- **THEN** он отображается без пометки доставки

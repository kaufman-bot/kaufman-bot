# Spec Delta

## Purpose

Второй плагин бота: на сообщение пользователя «time» бот отправляет текущее время сервера, отформатированное в таймзоне пользователя. Демонстрирует работу плагина с данными профиля.

## ADDED Requirements

### Requirement: Ответ временем сервера в таймзоне пользователя

Плагин SHALL отвечать текстом с текущим временем сервера, когда текст сообщения пользователя — `time` после обрезки пробелов, без учёта регистра. Время SHALL быть отформатировано в таймзоне из профиля пользователя и SHALL включать дату, время (часы, минуты, секунды) и название таймзоны.

#### Scenario: У пользователя задана таймзона

- **WHEN** пользователь с профилем, содержащим таймзону `Europe/Moscow`, отправляет сообщение `time`
- **THEN** бот отвечает текстом, содержащим дату и время, соответствующие текущему моменту в `Europe/Moscow`, и название этой таймзоны

#### Scenario: Смещение таймзоны соблюдено

- **WHEN** два пользователя с таймзонами `Europe/Moscow` (UTC+3) и `Europe/London` (UTC+0/+1) отправляют `time` в один и тот же момент
- **THEN** время в ответах различается ровно на смещение между этими таймзонами

### Requirement: Поведение без таймзоны в профиле

Если таймзона пользователя не задана (null), плагин SHALL отвечать временем сервера в UTC и указывать это в ответе.

#### Scenario: Профиль без таймзоны

- **WHEN** пользователь без сохранённой таймзоны отправляет сообщение `time`
- **THEN** бот отвечает временем в UTC с указанием `UTC`

### Requirement: Отсутствие срабатывания на другие сообщения

Плагин SHALL не срабатывать на сообщения, отличные от точного `time` (без учёта регистра).

#### Scenario: Частичное вхождение

- **WHEN** пользователь отправляет сообщение `what time is it` или `тайм`
- **THEN** автоматического ответа бота нет

#### Scenario: Лишние символы

- **WHEN** пользователь отправляет сообщение `time?`
- **THEN** автоматического ответа бота нет

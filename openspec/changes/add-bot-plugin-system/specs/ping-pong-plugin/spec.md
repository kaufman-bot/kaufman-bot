# Spec Delta

## Purpose

Первый плагин бота: эхо-ответ «pong» на сообщение пользователя «ping». Демонстрирует контракт плагинной системы на простейшей реакции.

## ADDED Requirements

### Requirement: Ответ pong на сообщение ping

Плагин SHALL отвечать текстом `pong`, когда текст сообщения пользователя — `ping` после обрезки пробелов, без учёта регистра. Ответ SHALL доставляться как обычное сообщение бота в диалоге пользователя.

#### Scenario: Сообщение в нижнем регистре

- **WHEN** пользователь отправляет сообщение `ping`
- **THEN** бот отвечает `pong`, ответ сохранён в диалоге

#### Scenario: Регистр и пробелы игнорируются

- **WHEN** пользователь отправляет сообщение `  PING  ` или `Ping`
- **THEN** бот отвечает `pong`

### Requirement: Отсутствие срабатывания на другие сообщения

Плагин SHALL не срабатывать на сообщения, отличные от точного `ping` (без учёта регистра): вхождения подстроки, добавленные знаки препинания и другие тексты не триггерят ответ.

#### Scenario: Частичное вхождение

- **WHEN** пользователь отправляет сообщение `ping pong` или `пинг`
- **THEN** автоматического ответа бота нет

#### Scenario: Лишние символы

- **WHEN** пользователь отправляет сообщение `ping!`
- **THEN** автоматического ответа бота нет
